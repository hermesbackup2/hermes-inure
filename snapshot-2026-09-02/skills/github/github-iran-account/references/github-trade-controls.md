# GitHub Trade Controls — Iran account quotes (verbatim from support modal)

These are the exact statements GitHub's support flow presented to an Iran-based user
whose account was suspended. They corrected the earlier wrong assumption that making
repos public would restore access.

> "GitHub cloud services, including public and private services, are available in Iran,
> but restricted parties or accounts flagged in error need a Support review."
>
> "Based on GitHub's official policy, GitHub has an OFAC license to provide all
> GitHub.com cloud services in Iran, including public and private services, for
> individuals and organizations, both free and paid. That means Iran-based accounts
> are not limited to public repositories only."

> "I can't confirm that your suspension was caused by a private-repository restriction.
> The published policy does not support that conclusion for users in Iran."
>
> "Making your repositories public is not something the documentation says will restore
> access for an Iran-based account. That public-conversion path is documented for some
> other trade-restricted situations, but the Iran policy says GitHub services in Iran
> include both public and private services."

> "GitHub also states that if an individual believes they were flagged in error, they
> can appeal by providing verification information to GitHub Support. If GitHub receives
> sufficient information to verify that the person is not affiliated with a U.S.-sanctioned
> jurisdiction for which GitHub does not have a license, or is not otherwise restricted by
> U.S. economic sanctions, the flag will be removed."

Policy points the modal highlighted:
- Iran is covered by GitHub's OFAC license for cloud services, including all public and
  private services for individuals and organizations, both free and paid.
- Travel or location signals may affect account status; affected users can use the appeal
  process if flagged unintentionally or in error.
- Nationality and ethnicity are NOT used to flag users for sanctions restrictions.
- SDNs, other denied/blocked parties, and certain government officials may still be
  restricted, wherever located.
- If verified not in a restricted category, the flag WILL be removed.

Primary doc referenced: GitHub and Trade Controls (https://docs.github.com/en/site-policy/other-site-policies/github-and-trade-controls)
